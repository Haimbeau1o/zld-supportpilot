# 当前 Issue 依赖与并发分析

## 分析原则

- 先找前置基础能力，再找业务主线，再找融合点
- 对接口、权限、数据模型存在强耦合的工作，优先视为串行或“先约定后并行”
- 对输入输出清晰、边界稳定的工作，可以并行推进
- 当多个并行 Issue 最终会汇入同一业务链路时，提前创建融合 Issue
