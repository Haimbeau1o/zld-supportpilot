# 方案设计

## 设计目标

把学习型研发流程抽象成通用能力，不绑定某个具体业务项目。

## 模块边界

- skill 只定义通用方法，不嵌入 ZLD 专属模块边界
- references 文件提供固定交付物清单和并发性分析法

## 数据流 / 时序

- 识别用户目标 → 建立任务卡 → 做调研和方案比较 → 分析 Issue 依赖与并发性 → 写实施计划 → 实现并补中文注释 → 验证与复盘

## 接口或数据结构草案

- 本 skill 的固定输出包括：Issue 依赖图、执行波次表、融合 Issue 建议

## 错误处理与边界条件

- 如果缺少 Issue 依赖判断，则默认不能直接并行
- 如果只有结论没有调研过程，则视为工作包不完整

## 中文注释计划

本 Issue 主要是 skill 与文档，不涉及业务代码；中文解释重点体现在 skill 的固定流程、反模式和并发性规则。
