# 任务卡

## 基本信息

- Issue 编号：#5
- Issue 标题：主线：知识库与文档上传
- 类型：主线
- 所属阶段：M2 - 工单与知识库

## 背景与问题

没有知识入口和文档上传能力，后续的异步解析、RAG 检索和 AI 回答都没有稳定的数据来源与存储挂载点。

## 目标

建立在认证、租户与 RBAC 基础之上的最小可用知识库与文档上传链路，让系统能够在租户边界内创建知识库、上传原始文档并追踪文档元数据与上传状态。

## 范围

### 包含

- 知识库实体与文档元数据模型
- 文档上传状态模型
- 知识库创建、查询基础 API
- 文档上传与文档元数据查询 API
- 存储接入抽象与内存适配
- 与身份上下文联动的权限边界
- 对应测试、中文注释和工作文档沉淀

### 不包含

- 文档切块、解析、向量化与异步流水线
- 检索召回与回答生成
- 文档在线预览、下载和版本管理
- 外部对象存储真实接入（如 MinIO 正式实现）
- 复杂筛选、分页和全文搜索
