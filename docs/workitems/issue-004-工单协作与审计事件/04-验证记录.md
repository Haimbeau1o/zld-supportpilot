## TDD 证据

- 服务层既有红绿循环已通过：`AddTicketComment`、`ListTicketTimeline`、内部备注可见性、指派/状态审计事件均有测试覆盖。
- HTTP 层本轮先补测试，再运行定向测试，首次失败原因为评论 / 时间线路由不存在，返回 `404`。
- 在补齐 `POST /api/v1/tickets/{id}/comments` 与 `GET /api/v1/tickets/{id}/timeline` 以及 app 装配后，定向测试转绿。

## 关键验证点

- 终端用户可新增公开评论。
- 终端用户不能新增内部备注。
- 客服查询时间线时可看到 `created` 审计事件和公开评论。
- 终端用户查询时间线时看不到内部备注。
- 评论接口和时间线接口都受鉴权中间件保护。
- `New()` 装配出的应用默认具备工单协作能力，不会出现“路由存在但能力未启用”的假接线。

## 手工验证说明
