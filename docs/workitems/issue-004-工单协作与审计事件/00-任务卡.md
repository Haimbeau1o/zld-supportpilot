- 类型：并行
- 所属阶段：M2 - 工单与知识库

## 背景与问题

`#3` 已经完成工单创建、指派和状态流转的主流程，但工单仍然缺少“协作痕迹”：谁补充了处理说明、谁写了内部备注、指派何时发生变化、状态何时被修改，这些都还无法追踪。没有这些记录，工单系统的真实度和可审计性会明显不足。

## 目标

为工单主流程补齐协作与审计能力，让系统能够沉淀评论、内部备注、指派变更和关键动作时间线，并通过统一接口对外查询。

## 范围

### 包含

- 工单评论与内部备注模型
- 评论 / 备注写入接口
- 指派变更审计事件
- 状态流转审计事件
- 工单协作时间线查询接口
- 中文注释、测试和工作文档沉淀

### 不包含

- 评论编辑 / 删除
- 富文本、@提及、附件上传
- SLA、催办、订阅通知
- 外部消息通知（邮件 / IM）
- 工单 AI 分类、摘要、回复草稿（属于 #8）
