# 任务卡

## 基本信息

- Issue 编号：#2
- Issue 标题：主线：认证、租户与 RBAC 基础
- 类型：主线
- 所属阶段：M1 - 基础能力

## 背景与问题

服务台项目需要先建立稳定的身份上下文与权限边界，否则工单、知识库与 AI 能力都无法安全接入。

## 目标

建立面向后续业务模块的认证、租户与 RBAC 基础，让系统能够识别“谁在访问、属于哪个租户、拥有哪些权限”。

## 范围

### 包含

- 用户、组织、成员关系模型
- 登录认证基础
- 角色与权限模型
- 鉴权中间件与身份上下文传递
- 最小可用的注册、登录、获取当前身份接口

### 不包含

- SSO / OAuth 第三方登录
- 邀请制组织管理
- 细粒度 ABAC
- 刷新令牌轮换与设备管理
