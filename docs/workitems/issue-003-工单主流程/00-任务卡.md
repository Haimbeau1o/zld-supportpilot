## 背景与问题

工单是服务台的核心协作对象。只有先建立清晰的工单主流程，后续的评论协作、审计事件、RAG 检索与 AI 辅助能力才有稳定的挂载点。

## 目标

建立在认证、租户与 RBAC 基础之上的最小可用工单主流程，让系统能够在租户边界内创建工单、查询工单、指派处理人并执行可验证的状态流转。

## 范围

### 包含

- 工单实体、优先级、分类、处理人等核心字段
- 工单状态模型与状态流转规则
- 创建、列表、详情等基础 API
- 指派处理人与状态流转 API
- 与身份上下文联动的权限边界
- 对应测试、中文注释和工作文档沉淀

### 不包含

- 评论、内部备注、关注人等协作能力
- 审计事件流水与操作历史回放
- SLA、催办、批量操作等增强能力
- AI 分类、摘要、回复草稿
- 数据库持久化与复杂检索筛选
